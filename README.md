# CampusTimetableBeauty 校园课表美化小程序
> 项目：校园课表美化小程序
技术栈：原生微信小程序 + WXML + WXSS + JavaScript

## ✨ 项目简介
一款校园课表解析美化微信小程序，支持解析Excel/PDF课表文件，实现课表可视化渲染，支持主题切换、课程编辑、课表截图导出。

## 📦 功能清单
1. Excel/PDF课表文件解析读取
2. 课表周次拆分与可视化展示
3. 多套主题颜色切换
4. 课程增删编辑
5. 课表预览、截图导出保存

## 🚀 运行方式
1. 下载项目源码
2. 使用微信开发者工具导入项目根目录
3. AppID选择【测试号】直接运行

## 📂 目录结构
- pages：业务页面
- components：自定义组件
- utils：工具函数、文件解析模块
